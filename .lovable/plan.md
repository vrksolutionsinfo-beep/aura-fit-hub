# Aura Fitness website

## Goal
Build the complete premium, cinematic Aura Fitness website from the supplied brief, using TanStack Start as the approved workspace-compatible replacement for Next.js.

## What I’ll build
- A dark charcoal, metallic-gold, and deep-red design system with bold condensed typography.
- Shared floating navigation, polished mobile menu, footer, contact actions, and accessible motion.
- Routed pages for Home, About, Programs, Trainers, Pricing, Gallery, and Contact.
- A cinematic home page with generated fitness imagery, restrained atmospheric 3D particles, editorial sections, programs, pricing, gallery, testimonials placeholders, and strong calls to action.
- Interactive gallery lightbox, mobile-friendly enquiry form states, subtle parallax/tilt, and reduced-motion support.
- Centralized editable business data for prices, programs, trainers, gallery, contact details, and placeholders.
- Unique metadata for every page, semantic structure, accessibility, and mobile optimization.

## Technical details
- React 19, TanStack Start, Tailwind CSS v4, Motion for React, React Three Fiber, and Three.js only.
- 3D will remain lightweight and client-only, with graceful mobile and reduced-motion fallbacks.
- The enquiry form will validate and show a clear local success state; no unconfigured delivery service will be implied.
- Trainer profiles, testimonials, and unverified statistics will remain clearly marked editable placeholders rather than fabricated claims.

## Validation
- Check all routes and interactions in the browser at desktop and mobile sizes.
- Verify the 3D atmosphere renders, navigation and lightbox work, forms validate, and no visual overlap or runtime errors remain.
